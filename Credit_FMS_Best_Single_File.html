Quick guide

A practical guide to working with Credit Desk.

1. Create a facility record

Click New file. Enter the date received, customer, CIF, product and amount, then choose the current stage, stage date, responsible officer and next action. Save to generate a reference number automatically.

2. Keep stage dates accurate

Stage date means the date the facility entered its current stage. Pending days are calculated from this date for active stages. Update the stage date whenever the file moves to a new stage.

3. Use the alerts

Overdue actions turn red. Stage SLA breaches turn amber. Due-soon actions and renewal / cash build-up reminders are based on the dates and windows in Settings. Missing next actions are flagged for active files.

4. Checklists and progress

Use Document checklist and Disbursement checklist to mark each requirement Pending, Received / Done, or N/A. Completion percentages exclude N/A items. Change the standard checklist in Settings.

5. Email notifications

Use the Email draft action on a facility to open a pre-filled message addressed to the responsible officer and CC the branch manager. Email sending is not automatic in a standalone HTML file.

6. Back up your data

Export a JSON backup regularly. Data is saved in this browser's local storage and is not shared between computers or browser profiles. Import a backup to restore it on another device.

Important: This is a local single-file prototype, not an approved bank system. Browser storage and the Settings password do not provide production-grade security, access control, audit trails or shared data storage. Do not enter real confidential customer data.
